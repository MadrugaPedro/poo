### Instalação do Git LFS no Windows

1. **Instalar o Git LFS**

```powershell
winget install GitHub.GitLFS
```

2. **Fechar o PowerShell e abrir uma janela nova**

3. **Habilitar o Git LFS para o usuário**

```powershell
git lfs install
```

4. **Verificar a instalação**

```powershell
git lfs version
```
